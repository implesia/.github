# implesia/.github

Organization-wide profile and community health files for **[Implesia IT Ltd.](https://github.com/implesia)**

## What's in this repository

| Path | Purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The public overview shown on [github.com/implesia](https://github.com/implesia) |

GitHub automatically displays `profile/README.md` from this public repository on the organization's
overview page. Default community health files (for example `CONTRIBUTING.md`, `SECURITY.md`, or issue
templates) can also be added here; they apply to every repository in the organization that doesn't
define its own.

## Updating the profile

Edit [`profile/README.md`](profile/README.md) and commit to `main` — the change appears on the
organization page right away. Keep it public-safe: no server addresses, internal URLs, or secrets.
